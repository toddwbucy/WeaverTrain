# Reports

Records of what happened: experiments, their results and where the work stands. They
are not code and not Specs; a report does not authorize code. Each report is dated
(`YYYY-MM-DD-<topic>.md`). A directory with the same date and topic holds the result
files that the report refers to.

Text from `nvidia/Nemotron-SWE-v1` (CC BY 4.0, NVIDIA) appears in some result files, in
masked form: code, commands, paths and program output are replaced by `[[Cn]]`
placeholders. Model rewrites of that text are marked with the model that wrote them.
No text of the ASD-STE100 standard is in these files: the rules given to the models
and the checker's repair notes are derived from it and stay local.
